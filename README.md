# Ritual_kkr
RFP社群使用的神秘小插件，让伟大的 Mint_kkr 在加入服务器时自动全服播放花之塔

Velocity插件，强依赖 [Allmusic]([https://](https://github.com/Coloryr/AllMusic)) ；

---

具体使用方法：

Mint_kkr进服自动触发，或：
``` /kkr ```

---

自定义 UUID：

[MintkkrAuto.java](/src/main/java/net/leitingsd/mintkkr/MintkkrAuto.java)

11: UUID.fromString("3dc46bcf-c8dd-4546-a7a5-e7d658c9e88a")将双引号内内容改为目标用户UUID并编译；
